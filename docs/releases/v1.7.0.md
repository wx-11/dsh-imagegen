# v1.7.0 · 可编辑文字与 Logo 海报

在无限画布的图片工具栏或右键菜单选择「海报编辑：文字 / Logo」，给现有图片添加可编辑标题、价格和品牌 Logo。

## 新功能

- 文字独立成层：支持多行文字、自动换行、字号、颜色、加粗、字体类别和对齐方式。
- 上传 PNG / JPG / WebP Logo，保留透明度；拖动或输入像素坐标调整位置，按比例调整 Logo 宽度。
- 图层前后顺序、删除、撤销和重做；修改未保存时关闭编辑器会提示放弃或继续编辑。
- 预览与 PNG 导出共用一个 Canvas 渲染器。图片最长边最多 4096 像素，较大的原图会等比缩小。
- 「保存到画布」生成新的图片节点，并保存原始底图、文字和 Logo 图层。再次打开该节点可继续编辑；原图节点保持原样。
- 全程本地图片合成，不调用生图模型、不消耗模型额度。Logo 保存在当前 DSH 宿主的画布素材目录。
- 补齐中文、英文、俄文界面文案。

## 保存与兼容性

- PNG 导出是合成图片，不含可编辑图层；要保留工程，请使用「保存到画布」并等待画布状态显示已保存。
- 本版用于在图片上新增文字与 Logo；不会自动识别或擦除底图中已有的文字。
- 新增元数据沿用画布 version 2，旧画布无需迁移。生成、下载、图片引用继续使用普通图片资产。
- 修复自动保存响应返回时覆盖较新本地编辑的问题；切换画布后不再用旧画布的保存响应替换当前画布。
- 不新增运行时依赖。安装包只携带发布说明和技能配置文档，演示视频与截图继续保留在仓库，减少下载体积。

## 安装

下载本 Release 的 `dickpy-dsh-imagegen-1.7.0.tgz`，使用实际文件路径安装：

```bash
dsh plugin --profile web add ./dickpy-dsh-imagegen-1.7.0.tgz
```

桌面端使用其对应的 profile；安装完成后重启 DSH。发布到 GitHub Release 与发布到 npm 是独立操作，请以 npm 实际版本为准。
